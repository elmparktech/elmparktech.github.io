# AGENTS.md — ElmParkTech (`elmparktech.github.io`)

Guidelines for AI agents working in this repository.

## 1. Repository Purpose
This is the official static website for **ElmParkTech** (`https://elmparktech.github.io`), serving as:
- The studio homepage and app portfolio showcase.
- Individual app landing pages, support pages, and privacy policies (hosted under `/apps/<slug>/`).

## 2. Git Commit Rules
- **Commit each sizable unit of work** (e.g., initial setup, homepage build, adding an app, updating privacy policies, major styling updates) with a clear, concise commit message.
- **Do NOT mention any AI agent name, model name, or AI attribution** (no `Co-authored-by`, no "Generated by...", etc.) in commit messages, PRs, or code comments. Write commits as standard engineering commits.

## 3. Brand & Design System
- **Palette (derived from `elmpark-logo.png`):**
  - Deep Navy Surfaces: `#020a24`, `#01134d`, `#041e5b`, `#072b76`
  - Primary Accent (Coral-Red to Warm Orange): `#fc4836` → `#fd874a`
  - Secondary Glow / Wave Accent: `#1a47b8`, `#5035e8`
  - Text: `#ffffff` (primary), `#cbd5f0` (secondary), `#8fa3cf` (muted)
- **Visual Language:**
  - Architectural hairline section dividers and subtle structural grid lines.
  - Clean, modern typography, generous whitespace, and purposeful micro-interactions (including the interactive footer logo hover effect).
  - Keep the layout and visual identity distinct from `mhpartners.github.io`.

## 4. SEO, Accessibility & Markup Standards
- Use semantic HTML5 landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Maintain a strict heading hierarchy: **one `<h1>` per page**, followed by logical `<h2>` and `<h3>` levels.
- Every page must include:
  - Unique `<title>` and `<meta name="description">`
  - `<link rel="canonical" ...>`
  - Open Graph (`og:title`, `og:description`, `og:image`, `og:url`, `og:type`) and Twitter Card tags
  - JSON-LD structured data where appropriate (`Organization`, `SoftwareApplication`, `WebSite`)
- Provide descriptive `alt` text on all images and accessible `aria-label`s on icon-only controls.
- Keep `.nojekyll` in the root so GitHub Pages serves all paths cleanly without Jekyll interference.

## 5. Adding New Apps
When adding a new app in the future:
1. Create its dedicated directory under `/apps/<app-slug>/` with its landing page and `/apps/<app-slug>/privacy-policy/index.html` (or `/apps/<app-slug>/privacy.html` consistently).
2. Add the app entry to the homepage showcase.
3. Update `sitemap.xml` with the new URLs.
4. Commit the changes cleanly without AI attribution.
